# AC Boss Homepage Theme Design

## Purpose

Convert the AC Boss homepage into the same calm, image-led product-story system used by the rebuilt product-detail page.

## Page sequence

1. Spacious AC Boss product hero with one sleep-comfort promise and a single primary action.
2. Three concise benefit blocks: bed-level comfort, flexible placement, and quiet local control.
3. Alternating image-and-copy stories using existing sleep, wall-mounted, and technical-cutaway imagery.
4. Low-density expandable sections for technical detail, comparisons, and FAQs instead of dashboard-style inspectors and simulators.
5. A truthful compatibility conversation CTA with no false reservation confirmation.

## Visual expression

- Reuse the product-page warm off-white, charcoal, warm-grey, and restrained coral visual language.
- Reuse the `ac-*` component system where appropriate; homepage-specific selectors may extend it without affecting product-details content.
- Retire the current halftone/vector-telemetry hero, heavy card grids, pulsing system labels, and terminal voice.
- Use the canonical black AC Boss render and generated product visuals; do not use unrelated product concepts or branded imagery.

## Constraints

- Preserve the static HTML/CSS/JavaScript model.
- Preserve keyboard access, visible focus states, reduced-motion handling, responsive layouts, native `details` disclosures, and semantic headings.
- Do not present a transaction, warranty, shipping, compatibility, or performance claim without support.

## Success criteria

The homepage and product page feel like one considered AC Boss brand system, the product is recognisable in the first viewport, and visitors can understand the value proposition before seeing deeper technical details.
